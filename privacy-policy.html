nagomi studio(以下「当方」といいます)は、CultureVideoStudio(以下「本サービス」といいます)の運営にあたり、以下の方針に基づき個人情報および関連データを取り扱います。

1. 事業者情報

  • サービス名: CultureVideoStudio(nagomi studio)
  • 連絡先: nagomi.studio007@gmail.com

2. 本サービスの概要

本サービスは、動画コンテンツを自動的に生成し、YouTubeチャンネルへ投稿する内部システムです。本サービスは当方が運営するYouTubeチャンネルの管理を目的としており、当方以外の第三者ユーザーへのサービス提供は行っておりません。

3. 取得する情報とその利用目的

本サービスは、機能の提供にあたり、以下の情報を取得・利用します。

  • Google / YouTube アカウント情報: 本サービスはYouTube Data API Services を利用して、当方が管理するYouTubeチャンネルへの動画投稿、メタデータ(タイトル・説明・サムネイルなど)の設定、投稿状況の確認を行います。これには、OAuth 2.0 認証によって発行されるアクセストークンおよびリフレッシュトークンの保存が含まれます。
  • 動画生成に関する情報: 動画の台本、音声、映像素材などの生成・管理に必要なデータ。
  • 運用ログ: システムの動作状況、エラー、処理結果などの記録。

当方は、取得した情報を上記の目的以外に利用しません。

4. YouTube API Services の利用について

本サービスはYouTube API Servicesを利用しています。本サービスを利用することにより、お客様はYouTube利用規約に同意したものとみなされます。

また、Googleのプライバシーポリシーについては、以下をご参照ください。
Google プライバシーポリシー

5. データの第三者提供

当方は、以下の場合を除き、取得した情報を第三者に提供することはありません。

  • 法令に基づく場合
  • 本サービスの運営に必要な範囲で、以下の外部サービス提供者に処理を委託する場合(各社のプライバシーポリシーに基づき適切に管理されます)
    • Google LLC(YouTube Data API Services)
    • Amazon Web Services, Inc.(音声合成 Amazon Polly)
    • 動画生成AIサービス提供者(Volcano Engine / ByteDance関連サービス)
    • Anthropic PBC(コンテンツ生成・確認支援)

6. データの保存・セキュリティ

取得した認証情報(アクセストークン・リフレッシュトークン等)は、暗号化された内部システム(SecretStore)に安全に保管し、権限を持つ管理者のみがアクセスできるよう管理しています。

7. データの保持期間

認証情報は、本サービスの運用に必要な期間保持し、不要となった場合は速やかに削除します。
